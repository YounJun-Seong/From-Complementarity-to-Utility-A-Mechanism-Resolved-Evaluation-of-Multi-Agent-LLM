# 4_controlled_revision

**Paper:** §4.4, Figure 3, Appendix E (G5)

Controlled revision study (Control / Blinded / Opponent / Irrelevant) on 268 discordant pairs; BRR, HRR, DI. `results/cud/` holds the complementarity-utility synthesis (CUD) that preceded this study.

**Reproduce** (from this folder, with `PYTHONPATH=../../common`): `python code/sealed_analysis.py`; `python code/fig_paper.py` (Figure 3); `python code/cud_analysis.py`

All checks at once: `bash ../../tools/verify_reproduction.sh` from the repository root.
