# From Complementarity to Utility: A Mechanism-Resolved Evaluation of Multi-Agent LLMs

Code, model outputs, frozen protocols, and analysis scripts for every number and figure in the paper.
All analyses run from the shipped model outputs on a CPU, without LLM calls or a GPU.

```bash
pip install -r requirements.txt
bash tools/verify_reproduction.sh      # re-runs every analysis; checks every result file byte-for-byte
```

`tools/expected_results.sha256` holds the checksums of the result files as they were originally produced.
The script regenerates them from `studies/*/results` and compares.

## Analysis status

- **Prospective / sealed:** studies 2–6 primary analyses. Each sealed script was committed before its outputs existed and was run once.
- **Post-hoc:** everything in `studies/7_posthoc_audits`. Its definitions were committed before running;
  `POSTHOC_EXPERIMENTS.md` marks the two checks that were added after seeing the first judge outputs.
  The revision analyses ARR2-E1–E4 (compute-corrected C\*, candidate budget, selector extension, failure traces)
  are defined in `studies/7_posthoc_audits/POSTHOC_ARR2.md`; definitions were committed before running (`e6aab9a`), results in `8a17f69`.

## Re-running generation (optional)

Generation scripts (`run_*.sh`) need a vLLM installation (`VLLM_BIN`), the model weights
(Qwen2.5-14B-Instruct, Llama-3.1-8B-Instruct; Qwen3-32B-FP8 for the summary judge), and, for the MedAgents
multi-agent arm, a checkout of the released MedAgents code with the patches in
`studies/1_released_reevaluation/protocol/PATCHES.md` (`MEDAGENTS_DIR`). LLM caches are written to `cache/`,
which is not shipped. Server paths in logs have been replaced by `<REPO>`, `<HOME>`, and `<VLLM_ENV>`.

## Data

The benchmark questions are from MedQA, MedMCQA, and PubMedQA. Their licenses govern redistribution of the question text included in `data/` and `results/`.
The released multi-agent frameworks (MedAgents, MDAgents, MedLA, MedARC) are not included. Use their
original repositories.
